# Style reference (approved pilot: episode 1 opening, ev000000)

Audience: young fans of the anime. Tone: warm, light, lively; natural spoken English, contractions, exclamation
marks where the Japanese is excited. Text is mostly hiragana (written for children): keep vocabulary simple.

## Voices
| who | voice | example |
|---|---|---|
| Lucia | cheerful, emotional, a bit childish; "Whaaat?!", "you meanie!" | う〜‥‥　海斗の　いじわるぅ！ -> Hmph... Kaito, you meanie! |
| Hanon | bubbly, teasing, boy-crazy about Taro ("my Taro") | これでもう　わたしと太郎ちゃん　ラブラブカップルだもーん！ -> Now Taro and I are a lovey-dovey couple! |
| Rina | calm, boyish, terse ("I'd think", "huh") | ロウソクは‥‥じんじゃで　かうか -> The candle... I'll buy it at the shrine. |
| Kaito | casual guy, teasing, protective; calls the girls Lucia / Hosho / Toin | るちあも　まだまだ子どもだなぁ -> You're still such a kid, Lucia. |
| Hippo | polite, fussy, a little pompous (です/ます); honorifics dropped: るちあさん -> Lucia | |
| villains | haughty, mocking ("Hehehe... How foolish.") | ウフフ‥おバカさんね -> Hehehe... How foolish. |
| narration/SFX | sounds in parentheses, caps for loud | （ビューーーーッ！！） -> (WHOOOOOSH!!), （ドサッ！！） -> (THUD!!) |

## Pairs
- ねえねえ　しってる？　きょうは / 年に　いちどの　おおひきしおの日 -> Hey, hey, did you know? Today is / the year's biggest low tide!
- すきだって　おもいが / あいてに　とどくんだって☆ -> your feelings will reach / that person! ☆
- えーっ　ホントにぃ！？ -> Whaaat? Seriously?!
- いいもん　ほうかごになったら / みんなで　どうくつへ　いこっ！ -> Fine! After school, / let's all go to the cave!
- （あーん　いいたいけど / はずかしくって　いえないよ〜） -> (Waaah, I want to tell him, but / it's too embarrassing to say!)
- エピソード　１　『あいのともしび』　おわり -> Episode 1 / "The Light of Love" - The End
- Card / board text: カードを手に入れたよ -> You got a card! ; ルーレットをまわして　おでかけしよう！ -> Spin the roulette and head out!

## Rules seen in the pilot
- The same line often exists three times, once per heroine (Lucia / Hanon / Rina versions). Translate each in that
  heroine's voice; keep the meaning identical across the three.
- Lines are split over the two lines of the box where it reads naturally; the split need not follow the Japanese.
- 〜 stretching: "Whaaat", "By the waaay". ‥‥ / … -> "...". 「」 -> "...", 『』 -> "..." (titles).
- Thoughts in （） stay in parentheses.
