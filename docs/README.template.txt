Mermaid Melody Pichi Pichi Pitch: Pichi Pichi Party (GBA) - English translation patch v{v}
=========================================================================================

Unofficial fan translation of Konami's 2003 Game Boy Advance board game
"Mermaid Melody Pichi Pichi Pitch: Pichi Pichi Party"
(マーメイドメロディー ぴちぴちピッチ ぴちぴちパーティー).
No ROM is included and none will be provided. Use your own dump.

What is translated
- The whole script: all 32 episodes of All-Out Pitch, board events, the three
  heroines' versions of every scene, battles, cards, items, clothes, menus and
  help text (new proportional English font, variable-width renderer).
- Pictures with text: title logo, mode select and menus, episode title cards,
  board banners and labels, battle graphics, results screens, dress-up mode,
  name entry (Latin letters), copyright screen and the staff roll.
Names follow the official English localisation (Lucia, Hanon, Rina, Kaito, Hippo,
Taro Mitsuki, Nikora). Honorifics are dropped; names are in Western order.

How to patch
  Apply {patch} to the base ROM with Floating IPS (Flips), beat, or
  RomPatcher.js (https://www.marcrobledo.com/RomPatcher.js/). Patch SHA-1: {psha}

Notes
- Tested in MesenCE 2.2.1 (scripted headless play). Start from a cold boot, not from a
  savestate made with the Japanese ROM. Save files from the Japanese version work, but a
  cartridge name entered in kana will show as kana.
- Staff names were romanised from the game's credits; a few readings may be wrong.
- Known issues: see the list at the end of this file.
